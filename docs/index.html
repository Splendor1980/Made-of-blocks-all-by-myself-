mc-agent

Make a Minecraft skin or a structure datapack — no coding, no AI pixels.

Download (Windows) View source on GitHub
NOT AN OFFICIAL MINECRAFT PRODUCT, NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT. This tool creates original skins and textureless datapacks; it never contains official game assets.

Skins

Start from a template (Knight / Mage / Robot), recolor by body part, import your own PNG, paint UV regions, and Export PNG. Works fully offline — no model required.

Builds & datapacks

Pick a shape (house, pyramid, tower, bridge, ring…), preview it live, and generate a datapack (folder or .zip) you drop into a fresh world and run with /function.

Made for beginners

One-click Windows installer, Idea cards to get started, a clear onboarding consent screen, and a "How to wear" guide. No coding, no account needed to run it.

How to get it (Windows)

  1. Download the latest mc-agent-win.zip from Releases on GitHub.
  2. Unzip it anywhere (right-click → Extract all).
  3. Run start.cmd. That's it — no Node.js or install steps.

On first run, SmartScreen may ask “More info → Run anyway” (the app is free/unsigned). Read the included INSTRUCTIONS.md for the full guide.
